# CipherVault 🔐

### Exploring private computation with encrypted data workflows

CipherVault is a lightweight educational tool exploring how private user data can move through a confidential computation workflow inspired by The Interfold ecosystem and Encrypted Execution Environments (E3s).

## Overview

Traditional applications require users to reveal their data before computation can happen.
